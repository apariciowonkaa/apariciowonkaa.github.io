02 / LOCATION & NETWORK

机房与线路，
先看访客在哪里。

地理距离只是一个起点。访问路径、运营商和使用时段也会影响实际连接表现。

01

从访问人群出发面向北美、亚洲或其他地区的业务，可以先考虑靠近主要访客的机房。

02

核对套餐可选范围不同系列的机房列表不同；购买前查看具体方案的 Datacenter feature highlight。

03

认识 CN2 GIA它是中国电信 CN2 网络的一种线路类型。并非所有机房都有；参考资料中的 E-Commerce 部分机房和 Ultra 方案提供该线路，具体以方案说明为准。

03 / CHECKOUT

购买步骤

第一次下单？这份简明购买教程把需要检查的事项放在一起。

  1. 01

    选择方案

    确定所需配置、机房和付款周期，查看套餐说明。

  2. 02

    加入购物车

    选择 Add to Cart，检查方案和订单金额。

  3. 03

    填写账户信息

    使用常用邮箱并按页面提示填写账户资料。

  4. 04

    验证并支付

    如有优惠码，先验证；确认金额后选择结算页提供的支付方式。

04 / PROMOTIONAL CODE

优惠码怎么用？

在购物车的 Promotional Code 栏输入代码，再点击 Validate Code。验证后检查订单金额和适用条件，再决定是否付款。

参考资料将 NODESEEK2026 和 BWHCGLUKKB 标为失效代码，属于历史信息；本页未实时验证当前优惠。

CHECK BEFORE PAYMENT

没有优惠码也可以继续选购

代码可能过期或不适用于所选方案。请以购物车的验证结果为准。
